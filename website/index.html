What is H#?

H# is an experimental programming language with a Python-like syntax that compiles to a custom bytecode VM. It's built from scratch with a focus on exploration of new programming paradigms and space computing concepts.

With built-in D3 system for space operations, coroutine-based concurrency, and an optimizing compiler, H# pushes the boundaries of what's possible in language design.

Core Capabilities

◙

Space Computing

Built-in D3 emotional system for spatial computing operations. New paradigm for handling complex geometric relationships.

◊

Parallel Execution

Coroutine-based concurrency with custom scheduler. Efficient multi-tasking without the GIL bottleneck.

◧

Optimizing Compiler

Multiple optimization passes from AST generation to register allocation. Clean and well-documented compiler pipeline.

▣

Functional First

First-class functions, closures, and lexical scoping. Built-in support for functional programming patterns.

▨

Python Interop

Seamless integration with Python host functions. Leverage the entire Python ecosystem from H# code.

◈

Extensible

Modular standard library design. Easy to add new modules and extend the language capabilities.
