# Code Teacher

> **学习型编程工作台** — 100% 用 H# 语言开发
>
> 助手仅作为学习引导角色（思路提示、错误解析、知识讲解），不直接参与代码编写。

## 项目结构

```
zzw_code_teacher/
├── app.hto                    # 入口：角色选择画面（学生 / 教师）
├── common/                    # 两端共用模块
│   ├── theme.hto              # 现代化暗色主题（Vercel/Linear 风格）
│   ├── widgets.hto            # UI 组件库（圆角卡片 / badge / 导航项等）
│   ├── data_store.hto         # 题目/用户/提交的文件持久化 + 内置示例数据
│   └── ai_tutor.hto           # 学习助手引擎（错误解析/思路提示/概念讲解/代码反馈）
├── student/
│   ├── student_ide.hto        # 学生端 IDE
│   └── run.hto                # 单独运行入口
└── teacher/
    ├── teacher_admin.hto      # 教师端管理后台
    └── run.hto                # 单独运行入口
```

## 运行方式

从项目根目录运行：

```bash
# 完整流程（角色选择 → 对应端）
python3 hsharp.py zzw_code_teacher/app.hto

# 直接启动学生端
python3 hsharp.py zzw_code_teacher/student/run.hto

# 直接启动教师端
python3 hsharp.py zzw_code_teacher/teacher/run.hto
```

## 设计语言

参考 Vercel / Linear / Next.js 文档站的现代暗色风格：

- **配色**：近黑背景（#0a0a0a），精细灰阶层次（#111 / #161616 / #1c1c1c / #222），微妙边框（#262626），强调色克制使用
- **圆角**：卡片 8px，按钮 6px，badge 3px
- **留白**：充足的内外边距，界面呼吸感
- **图标**：去除 emoji，用单字母（S/A/U 等）+ 圆角方块替代
- **状态指示**：小圆点（在线/就绪）、左侧激活条、badge 标签
- **命名**：去除"AI"标签，改为中性的"Assistant" / "学习助手"

## 学生端

极简顶栏（Logo + Tab 导航 + 用户头像）+ 三栏布局：
- **左侧题目列表** — 搜索框 + 题目卡片（题号、标题、难度 badge、通过率），hover/选中态
- **中央编辑器** — 文件标签 + 带行号的代码区（首行高亮）+ 底部输出面板（输出/终端/测试结果 Tab + 运行按钮）
- **右侧助手面板** — 标题"Assistant"+ 状态点 + 对话气泡（发送者标签区分）+ 快捷操作（思路提示/代码反馈/讲解概念）+ 输入框 + 发送按钮

## 教师端

统一视觉语言，顶部 Tab 切换四个管理面板：
- **题目管理** — 左侧题目列表卡片 + 右侧详情编辑卡片（字段两列布局 + 描述区 + 保存/删除按钮）
- **用户管理** — 表格（头像 + 角色 badge + 迷你进度条）+ 斑马纹/hover/选中态
- **提交审阅** — 左侧记录列表（结果 badge）+ 右侧代码查看（行号 + 代码区）+ 通过/驳回
- **评测统计** — 四个统计卡片 + 柱状图（提交数 vs 通过数，圆角柱子）+ 图例

## 助手引擎定位

**引导式学习，绝不代写。** 五种模式：

| 模式 | 触发 | 输出 |
|------|------|------|
| 错误解析 | 发送报错信息 | 识别错误类型 + 学习建议 + 启发式提问 |
| 思路提示 | 「思路提示」按钮 | 暴力法→优化法思路，不给完整代码 |
| 概念讲解 | 「讲解概念」按钮 | 定义 + 要素 + 例子 + 练习题 |
| 代码反馈 | 「代码反馈」按钮 | 学习性问题（死循环、==true、缺 return 等） |
| 默认对话 | 其他 | 说明能力边界，引导提问 |

## 技术基础

- **GUI 后端**：`gui_tkinter.py`（Python tkinter，注册 `gui_*` host 函数到 H# 解释器）
- **渲染原语**：`bootstrap/zzw_native.hto`（封装 native_* 调用）
- **数据持久化**：JSON 文件（`zzw_code_teacher/data/`，首次运行用内置示例数据）
