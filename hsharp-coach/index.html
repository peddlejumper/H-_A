教学意义与场景

让练习发生在真实的课堂里，
让反馈发生在学生需要的时候

它不只是作业批改工具，而是一套贯穿"课堂—作业—项目—考试"的教学环境。教师能即时看到全班的学习状态，学生能在遇到错误的第一秒获得解释，而不是等到下一节课再问。

为什么 line 9 报 KeyError？
在 cart.py:9 访问了 cart['totla']，但字典里的 key 是 'total'。这是拼写错误，不是逻辑错误。
改成 cart['total'] 后，建议再用 it.get('qty', 0) 避免另一个键不存在时的报错。
return sum( it['price'] * it['qty'] for it in items if it.get('qty', 0) > 0 )
能接入我们学校自己的模型吗？
可以。在控制台把模型地址指向学校内网，密钥只留在服务端。每次调用会记录学员 ID、token 数和时间，月底能导出对账单。
